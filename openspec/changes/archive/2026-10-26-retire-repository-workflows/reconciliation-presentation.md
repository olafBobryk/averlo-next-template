# Lifecycle, interaction, component and entity reconciliation

This is the clause reconciliation for tasks 2.1–2.4 and 5.1–5.6. Source names
and line ranges identify the immutable reviewed inputs in `source-baseline.json`;
they are historical identities, not live links into the retired router. Mixed
sections are split below. No clause is discarded. Behavioral clauses move to
maintained OpenSpec; topology and approvals move to nearest AGENTS; API teaching
stays at the Storybook owner; commands and evidence move to canonical procedures.
Root integration owns standard spec sync, WORKFLOWS names, assembly/profile closure,
source retirement and final acceptance. This batch does not introduce a button
selection policy, redesign, component index, motion system or entity framework.
